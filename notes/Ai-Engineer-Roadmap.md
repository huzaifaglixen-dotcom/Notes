## Phase 1: Strong Python Foundation (1-2 Months)

The entire world of AI revolves around Python, which makes it the essential starting point for this roadmap.

| Category | Details |
|---|---|
| **Topics to Learn** | Python Basics, OOP, File Handling, APIs, Async Programming, Virtual Environments, Git & GitHub |
| **Projects** | Weather App API · Chat Application · Web Scraper · REST API Client |
| **Resources** | *Python Crash Course* (book) · FreeCodeCamp Python · Corey Schafer (YouTube) |

---

## Phase 2: Data Structures & Algorithms (1 Month)

This phase builds the problem-solving skills needed for both AI interviews and general coding proficiency.

| Category | Details |
|---|---|
| **Topics to Learn** | Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Maps |
| **Practice Platforms** | LeetCode (Easy + Medium) · NeetCode Roadmap |

---

## Phase 3: Machine Learning Fundamentals (2-3 Months)

This is where the actual AI work begins.

| Category | Details |
|---|---|
| **Topics to Learn** | Linear Regression, Logistic Regression, Classification, Clustering, Feature Engineering, Model Evaluation |
| **Libraries** | NumPy, Pandas, Matplotlib, Scikit-Learn |
| **Projects** | House Price Predictor · Spam Detector · Customer Churn Prediction |

---

## Phase 4: Deep Learning (2 Months)

| Category | Details |
|---|---|
| **Topics to Learn** | Neural Networks, Forward Propagation, Backpropagation, CNN, RNN, LSTM |
| **Libraries** | TensorFlow, Keras, PyTorch |
| **Projects** | Image Classifier · Face Detection · Handwritten Digit Recognition |

## Phase 5: Generative AI & LLMs (2-3 Months)

This is the hottest and most in-demand skill set in the current market.

| Category | Details |
|---|---|
| **Topics to Learn** | What LLMs Are, Transformers, Embeddings, Tokens, Context Windows, Prompt Engineering |
| **Platforms to Use** | OpenAI · Claude · Gemini |
| **Projects** | AI Chatbot · PDF Chat · AI Content Generator |

---

## Phase 6: RAG Systems (1 Month)

Nearly every modern AI SaaS product today is built on top of RAG (Retrieval-Augmented Generation).

| Category | Details |
|---|---|
| **Topics to Learn** | Embeddings, Chunking, Vector Databases, Retrieval, Reranking |
| **Frameworks** | LangChain, LlamaIndex |
| **Vector Databases** | Pinecone, ChromaDB, Weaviate |
| **Projects** | Company Knowledge Bot · AI Support Assistant · Document Search Engine |

---

## Phase 7: AI Agents (1-2 Months)

Agentic AI is the defining trend of 2026.

| Category | Details |
|---|---|
| **Topics to Learn** | Tool Calling, Function Calling, Multi-Agent Systems, Memory Systems, Planning |
| **Frameworks** | LangGraph, CrewAI, PydanticAI |
| **Projects** | AI Booking Assistant · AI Travel Agent · AI Sales Agent |

| Category | Details |
